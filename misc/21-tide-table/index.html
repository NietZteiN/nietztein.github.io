Tide Table for Prose

A clock whose face is a single paragraph: every minute since midnight one word has been swapped for a synonym, so the morning sentence is unrecognisable by evening and comes back whole at midnight. The drift is deterministic per day, paragraph and seed, so a shared link shows everyone the same slowly failing text. Scrub the day with the slider, step with the arrow keys, and switch on diff to see what each word used to be.
