How it works. The library catalogue (assets/data/library.json) is shuffled by a seeded generator and dealt onto the shelf until it is full, so the same seed and the same window width always give the same shelf. The seed is today's date unless the address has ?seed=. Colours are the ones the Bookshelf tab paints its spines with; widths and heights come from a hash of each book's id. Nothing leaves your browser; only the sort order is remembered, in localStorage.
