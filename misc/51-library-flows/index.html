An alluvial diagram drawn by hand on SVG: each column is a facet of the catalogue, each node a value, and each ribbon the set of books that share every value along its path, so thickness is always a count. Nodes are ordered by a few passes of barycentre sorting to reduce crossings. Data: assets/data/library.json (889 books); unit names and genre hues are the Bookshelf tab's own. No libraries, nothing leaves the browser.
