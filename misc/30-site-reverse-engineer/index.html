Site Reverse Engineer

    
This page fetches the JavaScript that runs nietztein.github.io (main.js, blog.js, bookshelf.js, palette.js), cuts it into functions with a brace-matching scanner, and pushes any slice through the Obfuscation Playground's transforms one rung at a time. The Game deals eight rounds of real, obfuscated site code and asks which file it came from, what it does, which transform hit it, or what a renamed identifier used to be, with a daily seed so everyone gets the same puzzle. Deobfuscate me hands you a scrambled slice in a text box and measures, as you type, how far you still are from the original at the token level.

    
The site code being obfuscated here is Jack V. Le's own and, like the rest of the repository, is published under the Creative Commons Attribution-ShareAlike 4.0 licence (LICENSE-CC-BY-SA-4.0 at the repository root). The transforms are loaded from the playground (misc/04), which is built on acorn, acorn-walk and astring (MIT). Obfuscated output keeps behaviour but is not meant to run anywhere.

    
Shortcuts in the game: 1 to 4 answer, Enter next. The URL hash carries mode, file, function, difficulty and seed, so a link reproduces a puzzle.
