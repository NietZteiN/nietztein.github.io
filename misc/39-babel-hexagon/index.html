“The universe (which others call the Library) is composed of an indefinite and perhaps infinite number of hexagonal galleries… The Library is unlimited and cyclical.” Jorge Luis Borges, The Library of Babel (1941). Four walls of each hexagon hold five shelves; each shelf holds thirty-two books of four hundred ten pages; each page has forty lines of eighty characters, drawn from twenty-five symbols (here twenty-nine, with four punctuation marks).

A page is read as a 3200-digit number P in base 29 and an address (hexagon name in base 36, then wall, shelf, volume, page) as a second number A; the two are tied together by the affine bijection P = (a·A + c) mod 293200, which has an inverse A = a′(P − c), so every page has exactly one shelf and any text you type is sent back through the inverse to find its own. Hexagon names past about 3,000 characters wrap around to the start, so the Library is unlimited and cyclical.
