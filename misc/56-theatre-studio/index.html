How it works. The script is plain text in the format of Paper Theatre's stories. A short moment after each edit the text is saved in this browser (localStorage, key vn:studio:<draft>), parsed, linted and walked through every branch by the theatre's own engine (vn.js) in a background worker, and the stage on the right, which is the real Paper Theatre in preview mode, reads the draft again and returns to the line it was on. The examples are the published stories, copied into a draft: editing never changes a file on the site. The Studio writes nothing for you; every line in a draft is the author's. Nothing leaves your browser.
