The canvas is a spectrogram: 512 time slices across, 256 pitch rows from 100 Hz at the bottom to 8 kHz at the top on a log scale, brightness is loudness. To play it, every column becomes a Hann-windowed frame summing one sinusoid per lit row (fixed random phase per row, so overlap-add is click-free), rendered off the main thread. The analysis strip below runs a 4096-point FFT over the result so you can see what survived: thin horizontal detail plays as tones, vertical edges as clicks, blocky letters as chords.
