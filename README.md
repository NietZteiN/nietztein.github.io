# Jack V. Le's website

Static GitHub Pages site. Run `node scripts/serve.mjs` for a local preview and
`node scripts/test-all.mjs --site` for the repository checks and site smoke test.
Interaction checks are listed in [the QA guide](scripts/qa/README.md).

## Saved backups

Open **Saved** (`#/saved`) and choose **Export JSON** to back up this browser's
saved writing, research, books, experiments, and book notes. The backup also
retains valid IDs and notes whose public catalogue details are unavailable.

To restore a backup, choose **Import JSON**, select a Saved export, review the
proposed additions, and press **Restore**. Selecting a file or canceling the
preview does not change the collection. Existing items and their notes stay
unchanged; only reviewed missing items are added. Records saved in another tab
after the preview are kept too. Imported titles and URLs are ignored; displayed
details and links come from the site's public catalogues.

Backups stay on your computer. If browser storage is full or unreadable,
restored items remain available for the current visit and can be exported.
Keep that export before closing the page. A restore never replaces unreadable
original browser data.
