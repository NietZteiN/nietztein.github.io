About the file

The SVG has its size in millimetres and a matching viewBox, so it opens at scale in Inkscape, Illustrator or a print shop's viewer. Fonts are named, not embedded; a viewer substitutes if a font is missing.

Printing uses the browser's print dialog with the page size set to the chosen paper. Choose "Save as PDF" there for a file to send to a printer.
